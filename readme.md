# 面向实验教学的代码评测系统

## 项目简介

**JudgerToTeaching** 是一个专门为教育教学场景设计的在线代码评测系统。该系统能够自动化地编译、运行和评测学生提交的代码，通过资源监控、沙箱隔离和智能比对等技术，为编程课程提供安全、准确、高效的自动评分服务。

本项目作为毕业设计课题，面向实验教学和在线判题等实际应用场景，实现了完整的代码评测工作流，包括代码编译、安全执行、资源监控和结果验证等核心功能。

## 核心功能

### 1. 多语言编译支持
- **C/C++ 语言**：基于 GCC/G++ 编译器的完整支持
- **Java/Python**：预留框架接口，可扩展支持
- 智能编译错误捕获与反馈
- 编译输出重定向与解析

### 2. 安全沙箱执行
- **系统调用过滤**：基于 seccomp 的多层安全防护
  - 白名单模式：仅允许指定的系统调用
  - 黑名单模式：禁止危险系统调用
  - Kafel 策略语言支持高级安全策略
- **进程隔离**：通过 ptrace 实现进程跟踪与控制
- **信号处理**：捕获并处理运行时异常（段错误、中止等）

### 3. 资源监控与限制
精确监控和限制程序资源使用：
- **CPU 时间**：用户态 + 内核态时间总和
- **实际运行时间**：墙钟时间监控，防止超时
- **内存占用**：虚拟内存和堆内存使用量
- **栈大小**：调用栈深度限制
- **输出大小**：防止输出膨胀攻击
- **可执行文件大小**：二进制文件大小控制

实时监控线程确保超时程序被及时终止。

### 4. 智能答案比对
- **多测试用例支持**：可配置多组输入输出测试文件
- **逐行字符级比对**：精确到字符的差异分析
- **UTF-8 编码支持**：正确处理中文等多字节字符
- **相似度指标**：
  - 匹配字符数
  - 缺失字符数
  - 冗余字符数
- 详细的比对结果反馈

### 5. I/O 管理
- **三路管道系统**：独立管理 stdin、stdout、stderr
- **输入输出重定向**：将测试数据作为标准输入，捕获程序输出
- **非阻塞 I/O**：使用 poll() 机制高效处理 I/O
- **输出分离**：区分标准输出和错误输出

### 6. Java 集成接口
通过 JNI（Java Native Interface）提供 Java 调用接口：
- `compile()` - 编译源代码，返回编译结果
- `run()` - 执行程序，返回运行状态和资源使用
- `check()` - 验证输出，返回比对结果数组

可作为 Java 应用程序的后端评测引擎。

## 技术架构

### 核心技术栈
- **开发语言**：C++11
- **构建系统**：CMake + Makefile
- **编译工具链**：GCC/G++
- **进程管理**：POSIX fork/exec、ptrace、wait4
- **并发控制**：POSIX pthreads（多线程监控）
- **系统调用过滤**：libseccomp + libkafel
- **资源限制**：setrlimit 系列系统调用
- **I/O 管理**：POSIX 管道、poll() 多路复用
- **跨语言接口**：JNI（Java Native Interface）
- **文本处理**：正则表达式、UTF-8 字符集工具

### 系统架构层次

```
┌─────────────────────────────────────┐
│     Java 应用层（JNI 接口）          │
├─────────────────────────────────────┤

│  ┌────────┬────────┬────────┐      │

│  └────────┴────────┴────────┘      │
```

### 主要模块

**编译模块**（`compiler/`）
- 抽象编译器基类
- C 语言编译器（CCompiler）
- C++ 编译器（CXXCompiler）
- 编译错误捕获与报告

**执行控制模块**（`controller/`）
- ProcessController：进程调度与监控
- SubProcess：子进程环境配置
- Pipe3：三路管道管理
- 超时监控线程
- 系统调用跟踪

**答案检查模块**（`checker/`）
- AnswerChecker：输出比对引擎
- 逐行字符级比较
- UTF-8 文本处理
- 相似度计算

**通用模块**（`common/`）
- JudgeConfig：统一配置对象
- Result 系列：结果数据结构
- 工具类：文件操作、进程工具等
- INI 配置解析

## 评测流程

```
提交代码
    ↓
┌──────────┐
│   编译    │ → GCC/G++ 编译
└────┬─────┘
     │ CompileResult（编译状态、错误信息）
     ↓
┌──────────┐
│   执行    │ → fork + ptrace + 资源限制
└────┬─────┘
     │ ControllerResult（运行状态、资源使用）
     ↓
┌──────────┐
│ 输出比对  │ → 逐行字符级比较
└────┬─────┘
     │ CompareResult[]（比对详情）
     ↓
   评测结果
```

## 状态码说明

### 编译状态
- `OK (0)` - 编译成功
- `CE (1)` - 编译错误（Compilation Error）
- `SE (2)` - 系统错误（System Error）

### 运行状态
- `OK (0)` - 正常运行
- `SE (1)` - 系统错误
- `CLE (2)` - CPU 时间超限（CPU Limited Error）
- `RLE (3)` - 实际时间超限（Real Time Limited Error）
- `MLE (4)` - 内存超限（Memory Limited Error）
- `OLE (5)` - 输出超限（Output Limited Error）
- `RE (6)` - 运行时错误（Runtime Error）
- `IS (8)` - 非法系统调用（Illegal Syscall）

### 比对状态
- `RV_OK (0)` - 输出正确
- `RV_WRONG (1)` - 输出错误
- `RV_ERROR (-1)` - 比对出错

## 技术特点

### 进程监控
- 使用 `wait4()` 系统调用捕获进程状态变化
- 读取 `/proc/[pid]/status` 获取详细资源信息
- 独立监控线程实现精确超时控制
- 非阻塞高效的子进程跟踪

### 安全机制
多层次安全防护：
1. setrlimit 资源限制
2. seccomp 系统调用过滤
3. ptrace 进程跟踪
4. 信号处理器强制执行

### 文本比对
- UTF-8 字符集感知的字符匹配
- 优雅处理不同行结束符
- 提供细粒度相似度指标
- 支持批量测试文件

### JNI 集成
- 自动 Java↔C++ 对象编排
- 安全的内存管理与清理
- 从原生层到 Java 层的错误传播
- 支持复杂数据结构（数组、对象）

## 系统要求

- **操作系统**：Linux（依赖 ptrace、seccomp、fork/exec）
- **架构**：x86-64
- **编译器**：GCC 5+ / G++ 5+（需支持 C++11）
- **依赖库**：
  - libseccomp-dev
  - libkafel
  - libpthread（POSIX 线程库）
  - Java 8+ JDK（编译 JNI 接口时需要）
- **权限**：需要 root 权限（ptrace 和 seccomp 要求）

### 输出文件
- **可执行文件**：`JudgeToTeaching` - 独立运行程序
- **共享库**：`libjudge.so` - JNI 可调用库
- **安装路径**：`/usr/lib/libjudge.so`
- **配置目录**：`~/.ets/judge/`

## 配置文件

### config.ini
默认配置文件位于 `~/.ets/judge/config.ini`：
```ini
JudgeOutputFilePath = .ets/judge/JudgeOutputFilePath/
JudgeExeFilePath = .ets/judge/JudgeExeFilePath/
DefaultLimitedCPUTime = 10        # CPU 时间限制（秒）
DefaultLimitedRealTime = 10       # 实际时间限制（秒）
DefaultLimitedMemory = 5000       # 内存限制（KB）
DefaultLimitedStack = 2000        # 栈大小限制（KB）
DefaultLimitedOutputSize = 2000   # 输出大小限制（KB）
SysCallFilterMode = b             # 系统调用过滤模式
```

### filter-policy.txt
Seccomp 安全策略配置文件，使用 Kafel 语言定义允许的系统调用。
